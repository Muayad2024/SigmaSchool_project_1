# Muayad.dev — Personal Portfolio Website

A clean, responsive personal portfolio website built with **vanilla HTML, CSS, and JavaScript**. It showcases my background, technical skills, professional experience, and ways to connect with me — all wrapped in a lightweight, dependency-free package.

---

## 📖 Overview

This project is my personal portfolio site, designed to present who I am as a career-transitioning developer. It features a modern card-based layout, a fully functional **dark/light mode toggle** that remembers your preference, an interactive **experience timeline** with show/hide functionality, and a grid of social/contact links.

The site is built from scratch with no frameworks — just semantic HTML, CSS custom properties (variables) for theming, and plain JavaScript for interactivity.

---

## ✨ Features

- **🌗 Dark / Light Mode Toggle** — Switch themes with a single click. The choice is saved in `localStorage`, so it persists across page reloads and visits.
- **👋 Welcome Alert** — A friendly personalized greeting fires on page load using a template literal.
- **📅 Collapsible Experience Timeline** — A vertical timeline of professional roles with a **Show/Hide** toggle button to collapse or expand the section.
- **🛠️ Clickable Skill Badges** — Each technical skill links directly to the relevant certificate or documentation (freeCodeCamp, MDN, GitHub).
- **🔗 Social / Contact Grid** — Cards for GitHub, freeCodeCamp, Microsoft Learn, and a `mailto:` link to my email.
- **📱 Fully Responsive** — Adapts gracefully from desktop down to mobile using CSS Grid, `clamp()`, and media queries.
- **♿ Accessible Links** — External links use `target="_blank"` with `rel="noopener noreferrer"`.

## 🧰 Tech Stack

| Technology | Purpose |
|------------|---------|
| **HTML5** | Semantic page structure |
| **CSS3** | Styling, CSS Grid layout, CSS variables, responsive design |
| **JavaScript (ES6)** | Theme toggle, localStorage persistence, DOM manipulation |
| **SVG** | Inline icons for experience, social, and email cards |

No build tools, no frameworks, no external JS libraries — just the core web platform.
